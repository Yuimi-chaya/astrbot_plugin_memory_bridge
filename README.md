# 续忆桥

续忆桥是一个给 AstrBot 使用的会话记忆迁移与备份插件。它可以把一个会话里的聊天记录整理成记忆包，再导入到另一个会话、另一个 bot 或之后重新部署的 AstrBot 中，方便你把“以前聊过的事”带到新的地方继续使用。

它更像是一个“记忆搬家和管理工具”，不是嵌入模型、向量数据库那种完整的长期记忆系统。插件提供了轻量的记忆注入能力，但效果会受关键词、聊天内容质量、模型上下文长度等因素影响。更推荐把它用于备份、迁移、多会话整理和必要时的辅助回忆。

## 重要免责声明

记忆类插件会读取、整理、导出、导入或注入会话内容，这类操作本身都有一定风险。使用续忆桥前，请先确认你理解下面这些事项：

- 请及时备份重要记忆包、配置文件和提示词。插件只能辅助整理，不能保证任何数据永远不丢失。
- 不建议多个记忆插件、长期记忆插件或注入类插件混合使用。多个插件同时改写上下文时，可能互相影响，导致重复注入、记忆混乱或回复异常。
- 记忆注入会把旧会话内容加入模型上下文，可能对 bot 的人格、语气、偏好和回答方向造成轻微影响。
- 如果你使用了精心调试过的人格提示词、系统提示词或角色设定，请务必单独备份。记忆注入不能替代提示词管理。
- 记忆包可能包含私人聊天内容、QQ 号、群号、昵称、项目资料或其他敏感信息，请谨慎保存和分享。
- 清洗、脱敏和筛选功能不能保证完全准确，仍然可能保留不该保留的内容，或删掉你原本想保留的内容。
- 使用本插件即代表你已知晓并接受这些风险，并愿意自行承担备份、迁移、导入、注入和 WebUI 暴露带来的后果。

## 适合谁用

- 你有多个 AstrBot、多个群聊或多个私聊，希望把重要上下文迁移过去。
- 你准备重装、换服务器、换 bot，想提前备份会话记忆。
- 你希望把旧会话整理成可查看、可导入、可回滚的记忆包。
- 你想在 Web 页面里管理导入的记忆，查看哪些记忆正在参与注入。

## 主要功能

- **导出会话**：把当前会话历史导出成 zip 文件，便于保存和转移。
- **清洗记忆**：尽量去掉重复内容、无意义短句、日志、报错堆栈等噪声。
- **生成记忆包**：把保留下来的内容整理成 `memory_card`、chunks 和种子会话。
- **导入记忆**：把记忆包导入到指定会话中，用于后续继续参考。
- **WebUI 管理**：在浏览器里查看导出文件、导入记录、会话列表和注入记忆。
- **分条管理**：导入后的 chunks 可以单独启用、禁用、搜索和预览完整内容。
- **会话备注**：如果会话卡片只显示 QQ 号，可以在 WebUI 里手动设置昵称备注。

## 关于“长期记忆注入”

续忆桥目前提供的是轻量注入：当用户发消息时，插件会根据关键词从导入的记忆中挑选相关片段，尝试塞进本轮模型请求的上下文。

这和嵌入模型长期记忆不是同一种东西：

- 嵌入模型长期记忆通常会把文本向量化，检索能力更强，也更适合大量资料。
- 续忆桥不依赖向量数据库，部署更简单，更适合迁移、备份和人工管理。
- 注入结果不保证每次都命中，也不保证模型一定采用，只能作为辅助上下文。

如果你的目标是“稳定、自动、长期地记住大量知识”，建议优先考虑带嵌入检索的长期记忆方案。续忆桥更适合“我想把这段会话搬走、备份、整理，并在需要时让 bot 参考一下”。

## 基本使用

安装插件后，可以在聊天里使用 `/续忆` 相关命令。不同 AstrBot 环境可能会因为适配器、权限和部署方式有所差异，如果命令没有响应，先确认插件已经启用并重启 AstrBot。

常用命令：

```text
/续忆 status
/续忆 files
/续忆 clean_preview
/续忆 clean_export
/续忆 import_preview
/续忆 imports
/续忆 memory_status
/续忆 memory_test2 你想测试的问题
```

一般流程：

1. 在旧会话中执行 `/续忆 clean_export`，生成清洗后的记忆包。
2. 在 WebUI 或命令里选择这个记忆包，导入到目标会话。
3. 打开 WebUI 的“注入记忆”页面，确认导入记录是否启用。
4. 用 `memory_test2` 或 WebUI 测试面板检查某个问题能否命中相关记忆。

## WebUI

插件自带 WebUI，默认端口通常是 `2333`。如果你使用 Docker，请记得映射端口。

WebUI 里可以做这些事：

- 查看已识别的会话。
- 远程触发部分 `/续忆` 命令。
- 查看导出的 zip 文件。
- 上传或导入记忆包。
- 管理已导入记忆。
- 搜索、启用、禁用单条 chunk。
- 点击 chunk 查看完整上下文。
- 给只显示 QQ 号的用户设置本地备注。

建议给 WebUI 设置密码，尤其是你把端口暴露到局域网或公网时。

## 配置提示

大多数用户可以先保持默认配置。比较常用的配置项包括：

- `web_admin_enabled`：是否启用 WebUI。
- `web_admin_port`：WebUI 端口。
- `web_admin_password`：WebUI 密码。
- `cleaning_keep_recent_messages`：清洗时强制保留最近多少条消息。
- `memory_injection.enabled`：是否启用轻量记忆注入。
- `memory_injection.max_chunks`：每次最多注入多少条记忆片段。

如果你只是想备份和迁移，不一定需要开启注入功能。

## 隐私说明

续忆桥会读取并导出会话历史。生成的 zip 记忆包可能包含聊天内容、昵称、QQ 号、群号、项目细节或其他私人信息。

使用前请注意：

- 请把记忆包当作敏感文件保存，重要数据请多处备份。
- 不要把记忆包发给不可信的人。
- 群聊中使用前请考虑群成员隐私。
- WebUI 如果暴露到公网，请务必设置密码。
- 清洗功能只能尽量减少噪声和敏感内容，不能保证完全脱敏。
